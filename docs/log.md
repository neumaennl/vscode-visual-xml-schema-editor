## 2026-11-03
* **Update**: [ADR 003: Validators check, executors assume](architecture/003-validators-check-executors-assume.md) is new ([#402](https://github.com/neumaennl/vscode-visual-xml-schema-editor/issues/402)): the validator of a command checks everything its executor relies on, the executor does not check it again and states what it assumes with the helpers in `src/commandExecutors/assumeValidated.ts`, and the integration test `webview-src/__tests__/commandAgreement.test.ts` checks that both agree.
