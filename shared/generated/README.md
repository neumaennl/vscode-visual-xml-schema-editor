# Generated XML Schema classes

The TypeScript files in this folder are generated from `schema/XMLSchema.xsd` with `xsd2ts` from `@neumaennl/xmlbind-ts`. Do not edit them by hand. To regenerate them, for example after updating `xmlbind-ts`, run `npm run generate-classes-from-schema`.

See [Generated schema classes](../../docs/build-and-packaging.md#generated-schema-classes) and [Schema model](../../docs/schema-model.md).
